# Matter workspace review

Each workspace connects a client, matter brief, linked documents, deadlines,
Counsel Engine history, and chronological activity. Documents retain optional
references to existing platform records (`source_table` and `source_id`) so
legacy drafting output can be connected without migration or duplication.

Deadline completion and all Phase 2 create actions add auditable activity
entries. The reports and universal search pages consume the same data model,
providing operational visibility without changing legacy workflows.
