# Dashboard review

The dashboard uses live Phase 2 data rather than static counters:

- Open matters, clients, linked documents, and 14-day deadlines are counted.
- Deadline watch identifies overdue and seven-day deadlines.
- Active-matter and activity lists link into the relevant workspace.
- Time-aware greeting uses the signed-in username.
- Existing document tools remain accessible from the dashboard.

The responsive shared stylesheet provides compact navigation and single-column
layouts on small screens.
